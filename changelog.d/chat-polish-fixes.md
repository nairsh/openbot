### Changed

- The message box is slimmer, and the light theme background is whiter.
- The context meter is in the chat header, beside the model picker.
- A message that you send rises from the message box and grows into place, as in a phone's
  messages. A reply grows into place when it is complete.

### Fixed

- In Settings, the sidebar button and the sidebar edge line no longer show over the page title and
  the settings list.
- The microphone button's grey circle is in the center of the button.
- A sent message no longer flickers before it moves, and the message box no longer jumps up for a
  moment when you send to an agent that is not busy.
- With the medium chat width, the activity line under the last message stays in the center column.
