### Added

- Settings > General has a Chat width option. Medium puts the messages and the message box in a
  narrow column in the center of the chat. Full is the default.

### Changed

- Your messages are blue and the agent's replies are grey. A message that you send rises from the
  message box, and a reply grows into place.
- A reply shows when it is complete, not word by word. The activity line shows the work until then.
- The message box is a rounded box with round buttons. The context meter is to the left of the box.
- The steps row above a reply says "Worked for" and the time the turn took. Each step in the list
  has an icon for its kind of work, such as a web search or a change to files.
- The block above the message box that shows the agents that work on a request now shows only one
  row for each agent, with no "Waiting for replies" heading. It opens and closes smoothly.

### Fixed

- The status line of a working agent shows only the newest reasoning title, without `**` marks.
  Before, a model such as Codex showed each title with its marks, side by side.
