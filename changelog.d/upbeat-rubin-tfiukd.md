### Fixed

- In the agent dock, the `@` mention list opens above the message box. It no longer spans the full
  window width behind the dock.
- In the agent dock, a sent message rises from the message box and a reply grows into place, as in
  the main chat.
- While you dictate a long message, the message box changes to the tall layout. The words no longer
  show in a narrow column beside the recording controls.
