### Changed

- The working line names the tool the agent uses, such as "Using search threads…", and says "Thinking…"
  between steps. It no longer shows general text such as "Working through the next tool-assisted step…".
- A working agent's avatar no longer shows three dots. Before the agent names a step, the line says "Typing…".
- An agent's message actions stand beside its bubble, on the right, as your own actions stand beside yours. They stand at the middle of the message's height.
- An agent's message actions float at the right end of the message, so its answers stay stacked.
  "Worked for 29s" moved to the message's right-click menu, where it opens the trace.
- An agent's reply with a code block or another rich block shows in a bubble, like other replies.
- A live voice call shows in the chat as one "Voice call" row. Open it to see the messages of the call.
- The agent dock no longer has a "+" button. To add or remove dock agents, use Settings > Agent dock.

### Fixed

- In the dark theme, the line between the chat and a file or browser pane on the right is easier to see.
