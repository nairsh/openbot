### Added

- Fetch the model list of a custom provider. "Fetch models" uses the saved key and headers and
  lets you select the models to add.
- Test a model of a custom provider. "Test" sends one short message and shows the reply or the
  error.

### Changed

- The Models section of a custom provider shows the full model name, labels the token fields and
  shows the efforts as compact buttons.

### Fixed

- A custom provider that runs on Pi no longer adds a separate Pi tab to the model picker, and its
  models show one time only. Before, Pi showed as its own provider.
- Pi warnings no longer show as error messages.
