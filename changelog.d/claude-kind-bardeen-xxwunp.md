### Added

- Suggest your next message after an agent replies. The suggestion shows in the empty message box;
  press Tab to put it in the box, and it is not sent until you send it. Turn it on in Settings ›
  Agents › Next message suggestions. "Agent's model" uses Claude's own suggestions, which reuse the
  chat's prompt cache, and the agent's own model for other providers. "Chosen model" uses one model
  that you choose, such as a small, fast model, for every agent. Suggestions are off by default and
  show only for this computer's agents.
